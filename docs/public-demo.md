# Public competition demo (actual Gemma inference)

QuietOps can publish a browser-viewable, self-contained HTML report from a **genuine** local Gemma 3 1B inference run on a synthetic log fixture.

## Publish

1. Merge the PR containing the updated `.github/workflows/live-gemma.yml`.
2. Go to repository **Settings → Pages → Build and deployment → Source**, and choose **GitHub Actions**. GitHub Pages must be enabled in repository settings.
3. In **Actions → Real Gemma inference smoke test**, click **Run workflow** on `main` (or push to `main`). Confirm both `local-gemma` and `deploy-demo` succeeded.
4. Verify the live URL: **https://infraopsx.github.io/quietops/**. This URL is *only valid after deployment succeeds*. Open it from an incognito browser to check accessibility.
5. Add the verified URL to the DEV entry under **Demo**, alongside the source code link.

## What the public page shows

This is the actual generated `handoff.html` from the live workflow, not a mocked webpage and not a deterministic `preview` report. The companion generated `handoff.md` and `handoff.json` are also published. The fixture is synthetic, and the result is an example, not an assertion of verified incident root cause.

The live workflow validates `mode == "local-ai"`, the model name `gemma3:1b`, a nonempty model overview, and that every cited event ID exists in the grouped evidence.

## Safety and repeatability

The workflow runs Ollama on loopback inside GitHub Actions and uses only the repo's synthetic logs. Do **not** publish real customer or infrastructure logs. Every successful main-branch run updates the publicly visible demo; do not modify the fixture to contain secrets. GitHub Pages visibility can differ from repository visibility: confirm the Pages configuration.
